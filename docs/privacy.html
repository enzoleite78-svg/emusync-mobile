Política de Privacidade – EmuSync Mobile

Última atualização: 16 de novembro de 2026

O EmuSync Mobile é um app Android de código aberto que sincroniza saves de jogos e emuladores entre o celular e o Google Drive do próprio usuário, de forma compatível com o EmuSync para PC. Ele não tem ligação com o autor do EmuSync.

Quais dados o app acessa

  • Google Drive: o app lê e atualiza apenas os arquivos da pasta EmuSync_Data (lista de jogos, lista de dispositivos e os arquivos .zip com os saves). Ele precisa da permissão de acesso ao Drive porque essa pasta é criada pelo EmuSync de PC.
  • Pastas do celular: somente as pastas de saves que o usuário escolhe explicitamente.

O que o app NÃO faz

  • Não envia dados para servidores do desenvolvedor. Não existe servidor: a comunicação é só entre o celular e o Google Drive do usuário.
  • Não coleta estatísticas, anúncios, rastreamento ou dados pessoais.
  • Não compartilha nem vende dados para terceiros.
  • Não lê, altera ou apaga arquivos do Drive fora da pasta EmuSync_Data.

Dados guardados no celular

O app guarda, apenas na memória privada do próprio celular: o identificador do dispositivo, as pastas escolhidas, informações sobre o último sync e backups dos saves. Tudo é apagado ao desinstalar o app.

Uso dos dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados do Drive são usados exclusivamente para sincronizar os saves do próprio usuário.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions ou desinstalando o app.

Contato

Dúvidas: abra uma issue no repositório do projeto.

Summary (English)

EmuSync Mobile is an open-source Android app that syncs game saves between the device and the user's own Google Drive, compatible with EmuSync for PC. It only reads and updates files inside the EmuSync_Data folder and the device folders the user picks. There is no developer server; no analytics, ads or tracking; no data is shared or sold. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
